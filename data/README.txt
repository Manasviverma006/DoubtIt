DOUBTIT DATASET — 50+ ROW VERSION

IMPORTANT: Every record in this package is synthetic fictional test data.
These are NOT authentic complaints, real organisations, real people, real bank accounts,
real UPI IDs, or evidence of wrongdoing. Reserved .example.invalid domains and TEST IDs
are deliberately non-operational placeholders.

Record counts:
- campaigns.csv: 60 campaign rows
- complaints.csv: 120 complaint rows
- evidence.csv: 120 evidence rows
- relationships.csv: shared-identifier test edges

Why synthetic records?
They allow the team to test Linked Lists, Hash Tables, Graphs, BFS/DFS, Evidence Trees,
risk scoring, Max Heap, sorting, searching and file handling without making false claims
about real entities. The repeated test identifiers are intentional test cases.

For real public-source records added later:
- Keep them separate or set record_type to Publicly reported.
- Include a source URL/reference and date accessed.
- Preserve whether information is an allegation, investigation, or confirmed finding.
- Never treat a complaint or identifier match as proof of fraud.
